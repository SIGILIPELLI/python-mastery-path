Title: The C hello world, line by line (what each piece does)

Description:
Everyone copies the six-line C hello world, but almost nobody explains what each line is for. This Short walks the "Anatomy of the program" breakdown from the C Mastery Path setup lesson: what #include <stdio.h> does before compilation, why int main returns an exit status, what return 0 signals to the shell, and why gcc names your binary a.out when you forget the -o flag.
