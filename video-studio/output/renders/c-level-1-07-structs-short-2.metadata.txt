Title: C structs pass by value -- your function edits a copy

Description:
In C, handing a struct to a function copies the whole thing, member by member. So when the function changes its parameter, the caller's struct never moves. This Short shows the classic tryToMove gotcha from the Structs lesson and the one-line fix: pass a pointer instead.
