Title: Why a tiny C project still needs a header file

Description:
This C contact book is split across three files, and the header is the part beginners find confusing. contacts.h holds only the Contact struct and the function prototypes -- no logic. contacts.c holds the bodies. That's the interface/implementation split that every large C codebase is built on.
