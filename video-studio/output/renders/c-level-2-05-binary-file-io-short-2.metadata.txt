Title: Your C binary file works on your laptop and breaks everywhere else

Description:
A single fwrite call is the simplest way to save data in C -- and the fastest way to create a file that only your machine can read. This Short shows the two portability traps in raw binary dumps: byte order (endianness) and compiler-chosen struct padding, plus the fix (write field by field in a fixed byte order, with a magic number and version header).
