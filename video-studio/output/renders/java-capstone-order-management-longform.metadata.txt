Title: Build an Order Management API in Spring Boot — Full Java Capstone Walkthrough (JPA, Postgres, Docker, CI)

Description:
This is the Java Mastery Path capstone, built stage by stage: an Order Management Service — a Spring Boot REST API for creating, confirming, and cancelling orders, backed by JPA and Postgres. We go through the project layout and Maven setup, a validated JPA entity with its own state-transition guards, request and response DTOs that keep the entity off the wire, a Spring Data repository, a centralized @RestControllerAdvice exception handler, the service and controller layers, a Mockito unit test alongside a full @SpringBootTest + MockMvc integration test, and finally a multi-stage Dockerfile, a docker-compose.yml running the app against real Postgres, and a two-job GitHub Actions CI pipeline that tests before it ever builds an image. Every line of code shown is pulled directly from the capstone lesson — nothing invented, nothing skipped.
