Title: Build a CLI Contact Book in Java — Full Multi-Class Project Walkthrough With File Persistence

Description:
This is the Java Mastery Path Level 1 capstone, built end to end: a command-line contact book that adds, lists, finds, and deletes contacts, and persists them all to a plain-text file between runs. We go section by section through the project's own layout — Contact.java as an immutable data class with CSV serialization and a fromCsvLine factory that fails loudly on a malformed line, ContactStorage.java handling file persistence with Path, Files.exists, try-with-resources readers and writers, and graceful IOException handling, and ContactBook.java as the CLI layer that loads on start, dispatches commands through an arrow switch, validates argument counts, matches names with equalsIgnoreCase, uses a rebuild-the-list delete pattern, and saves after every mutation. Then we compile with javac, run a real add/list/find/delete session, and finish with the lesson's stretch goals. Every code block shown is pulled verbatim from the lesson — nothing invented.
