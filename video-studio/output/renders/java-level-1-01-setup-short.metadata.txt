Title: Java Doesn't Need a Build Step Anymore

Description:
Think Java always means compile-then-run? Since Java 11, you can launch a .java file directly with a single command -- no javac step required. This is lesson 1 of the Java Mastery Path: install the JDK, write your first Hello World, and use the single-file launch shortcut for quick tests.
