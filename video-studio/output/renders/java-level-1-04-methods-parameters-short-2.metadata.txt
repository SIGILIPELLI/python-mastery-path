Title: Java: when do you actually need `new`?

Description:
A question that trips up every Java beginner: when do you have to write the word `new`, and when can you skip it? This Short uses the `Counter` class from the Java Mastery Path methods lesson to show the split. Instance methods like `increment()` and `getCount()` act on one object's data, so they need a `Counter` built with `new`. A `static` method like `Counter.describe()` belongs to the class itself and needs no object at all.
