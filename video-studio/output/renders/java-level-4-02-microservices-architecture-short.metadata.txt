Title: One Java Annotation Stops Cascading Microservice Failures

Description:
When a downstream microservice starts failing, hammering it with retries just makes things worse. Spring's circuit breaker annotation from Resilience4j trips once failures cross a threshold, skipping the network entirely and routing straight to a fallback -- giving the failing service room to recover. This is one pattern from the microservices architecture lesson in the Java Mastery Path.
