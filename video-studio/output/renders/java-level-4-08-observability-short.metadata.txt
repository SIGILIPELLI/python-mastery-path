Title: The Java Logging Habit That Costs You Nothing

Description:
Most Java devs write log statements without thinking about the cost -- but SLF4J's `{}` placeholder syntax isn't just cleaner, it's how Logback skips building your log message entirely when that level is disabled. In this Short, see the real OrderService logging code from Level 4 of the Java Mastery Path and learn why concatenating strings in your logs quietly taxes every request in production.
