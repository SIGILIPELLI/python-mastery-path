Title: Design a CAN Sensor Node — Real-Time Embedded Systems Capstone (S32K, CAN Bus, Watchdog)

Description:
This is the Level 1 capstone of the S32K Mastery Path, walked through step by step: a real automotive-style CAN sensor node built on a hard 10-millisecond cooperative scheduler. We go through the precise requirement, the tick-driven architecture, the exact bit layout of both CAN frames (a 0x310 status frame out and a 0x311 command frame in), the INIT-safe-state-first state machine, the non-blocking main loop, the individual task functions for sensing, transmitting, receiving, and driving PWM with slew limiting, a full bench-test plan using a real CAN adapter, and the lesson's own closing question — an unguarded race between the CAN RX callback and the main loop's read of the shared command variable. Every line of code and every bit-table value shown is pulled directly from the capstone lesson; nothing invented, nothing skipped.
